# FairScan: Unbiased AI Decision Systems 🛡️🤖

**FairScan** is a no-code, high-speed AI auditing dashboard designed to detect, measure, and mitigate hidden biases in machine learning models. Built for the **IBM Bob Developer Hackathon**, it bridges the gap between complex algorithmic fairness and actionable human decision-making.

---

## 🚀 The Mission
Automated systems now decide who gets a loan, a job, or medical care. However, if these systems learn from flawed historical data, they amplify discrimination. **FairScan** provides a 30-second audit to ensure ethical AI isn't an afterthought.

## 🧠 Integrated Tech Stack
* **Orchestration Layer:** IBM Bob (Strategic Intelligence & Logic)
* **Reasoning Engines:** Google AI Studio (Gemini) & Claude
* **Core Logic:** Fairlearn (Demographic Parity & Equalized Odds)
* **Development Environment:** GitHub Codespaces & Gemini CLI
* **Deployment:** Vercel (Serverless Functions)

---

## 🛠️ How IBM Bob Powers FairScan
In this project, **IBM Bob** acts as the **Cognitive Orchestrator**. While our engines process the raw math, Bob provides the "Human-in-the-Loop" intelligence:

1.  **Contextual Explanation:** Bob translates raw fairness metrics (like a 0.12 Disparate Impact Ratio) into plain-English risk reports.
2.  **Mitigation Strategy Advisor:** When bias is detected, the **Bob-Dev Engine** suggests specific mitigation paths, such as data reweighting or threshold adjustment.
3.  **Compliance Audit:** Bob generates the final `IBM_BOB_Fairness_Report.txt` found in this repo, certifying the model for ethical deployment.

---

## 📂 Project Structure
* `/ibm-logic`: Contains the `bob_orchestrator.py` script and integration configs.
* `/dashboard`: The Vercel-powered frontend for no-code interaction.
* `IBM_BOB_Fairness_Report.txt`: **[CRITICAL]** The exported audit report generated by the Bob reasoning layer.
